## Problem Frame

Human needs 30-second scannable summary. Existing `apex audit` is too verbose.

## Decision Log

| Decision | Rationale | Rejected |
|----------|-----------|----------|
| AC pass/fail = check if all tasks are `done` + test pass evidence | Simple, verifiable; doesn't require deep semantic matching | Keyword matching in diff — fragile |
| Key warnings = all lines starting with bullet/dash in adversarial files | Simple extraction; adversarial files are already structured | NLP extraction — overkill |
| Decision prompt = static text (not interactive) | Works in all environments; human decides outside CLI | AskUserQuestion — only works in Claude Code |
| `--quick --json` shares same schema with extra `format: "quick"` field | Non-breaking | Separate schema — maintenance burden |
| Skip tests in --quick mode (fast) | Speed is the point; full audit runs tests | Always run tests — too slow for quick scan |
| Git diff uses last ship commit vs its parent | Already available in pipeline artifacts | Diff from main — unreliable if branch is old |
